# sahara-healthcare-suite
AfriHealth AI - Unified 3-in-1 Clinical Voice Care Suite for Sahara v2.5

## AfriSwitch evaluation data

The imported AfriSwitch audio and annotations remain available under
`data/afriswitch-samples/` for offline ASR evaluation and benchmarking only.
They are not used as live clinical transcripts, patient records, diagnoses, or
prescriptions. The live UI transcript is always produced by the configured
Intron streaming ASR endpoint.
